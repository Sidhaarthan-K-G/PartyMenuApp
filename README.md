# 🍽️ Party Menu App

A React-based food menu application where users can browse dishes, filter by category/type, search items, add/remove dishes, and view detailed ingredients in a separate page.

---

## 🚀 Features

- 🍔 Browse food menu with images and descriptions
- 🔍 Search dishes by name
- 📂 Filter by category (Starter, Main Course, Dessert, Sides)
- 🥗 Filter by food type (Veg / Non-Veg toggle)
- ➕ Add / Remove dishes to selection
- 📊 View total selected dishes count
- 🧺 Ingredients detail page for each dish
- 📱 Fully responsive UI (mobile, tablet, desktop)
- 🔄 Navigation using React Router

---

## 🛠️ Tech Stack

- React JS
- React Router DOM
- Context API (State Management)
- CSS (Custom Styling)
- Vite (Build Tool)
